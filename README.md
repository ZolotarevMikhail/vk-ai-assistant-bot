# VK-бот с ИИ-ассистентом для сообщества ВКонтакте

Бот принимает личные сообщения сообщества ВК и отвечает на них через
нейросеть (ProxyAPI) — клиент получает свободный разговорный ответ, а не
меню из кнопок. Помнит контекст диалога: помнит последние реплики
конкретного собеседника и учитывает их в ответе.

Проверен вживую: реальное сообщество, реальный ИИ-ответ, цикл
«сообщение → нейросеть → ответ» работает end-to-end.

## Как это работает

- **Long Poll** (библиотека vkbottle) — бот постоянно слушает новые
  сообщения сообщества, свой сервер не нужен;
- **ProxyAPI** (OpenAI-совместимый API) — запрос в нейросеть с системным
  промптом и историей диалога;
- **Характер и знания ассистента** задаются текстовым файлом
  `prompt-ассистента.txt` — правится без изменения кода.

## Файлы

- `bot.py` — запуск бота, приём сообщений, обработка ошибок VK API;
- `ai.py` — обращение к нейросети через ProxyAPI, память диалога
  (последние 8 реплик на каждого собеседника), две повторные попытки при
  сбое сети;
- `prompt-ассистента.txt` — персона и знания ассистента (заглушка —
  впишите описание своего сообщества);
- `requirements.txt` — зависимости;
- `.env` — секреты, в репозиторий не попадает (см. `.env.example`).

## Как запустить (для не-программиста)

1. Установите Python 3.10 или новее (на macOS — из python.org).
2. Получите токен сообщества ВК: Управление сообществом → Работа с API →
   Токены доступа. Нужны права «Сообщения», доступ «Управление».
   Также включите: Сообщения → «Настройки для бота» → Возможности ботов,
   Long Poll → событие «Входящие сообщения».
3. Откройте терминал в папке проекта и выполните:

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
cp .env.example .env
```

4. Откройте файл `.env` и заполните три строки:
   - `VK_TOKEN=` токен сообщества из шага 2;
   - `PROXYAPI_KEY=` ваш ключ proxyapi.ru;
   - `AI_MODEL=` модель, например `deepseek/deepseek-v4-flash`.
5. Запуск:

```bash
./venv/bin/python bot.py
```

6. Напишите что-нибудь в сообщения сообщества — бот ответит.

## Безопасность

- Токены хранятся только в `.env` (файл исключён из репозитория);
- в коде секретов нет;
- боту не нужно знать ваши персональные данные — только токены.

## Что дальше

Хостинг: для постоянной работы бота нужен всегда включённый компьютер —
Mac/PC или арендованный сервер (VPS, от ~150 ₽/мес). Инструкция по
переносу на VPS — типовая задача, при необходимости поможет настроить.
